Importa backup
Carica un file .json creato con "Esporta" o un backup giornaliero. Le aziende con lo stesso codice vengono aggiornate, le nuove aggiunte. Nessuna azienda viene eliminata.
📥
Esporta backup
Scarica una copia completa di tutte le aziende, dipendenti e scadenze in un file .json, da conservare sul PC o reimportare.
🛟
Backup automatico
Ogni giorno viene salvata automaticamente una copia online dei dati. Vengono conservati gli ultimi 30 giorni: in caso di necessità possiamo ripristinare una qualsiasi di queste copie.
